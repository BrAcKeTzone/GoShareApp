GOSHARE

Developer: J.P. Maniwang

Inspiration: Inspired by Akansh Sirohi's open-source work, though this tool is not intended to replace ShareX for Android.

Tech Stack: Written in Go (Golang) with an embedded modern web interface.

Platforms: This platform is only for Windows, Mac, and Linux.

GOSHARE is a lightning-fast, zero-friction cross-platform file-sharing utility that turns your desktop into a secure local web server, letting you seamlessly send and receive files over a local Wi-Fi network or hotspot without needing an active internet connection. Designed with a clean digital calculator aesthetic, it features an instantaneous zero-argument startup for desktop environments.
